# Blinkit Sales Dashboard

## About the Project

I made this project to analyze Blinkit sales data in Excel.
The dashboard helps to understand the sales performance and find
useful information from the data.

## Tools Used

- Excel
- Pivot Table
- Pivot Chart
- Slicer
- Excel Formulas

## What I Analyzed

- Total Sales
- Average Sales
- Number of Items
- Average Rating
- Sales by Item Category
- Sales by Outlet
- Sales by Outlet Size
- Sales by Location
- Sales by Fat Content
- Outlet Establishment Trend

## Dashboard

The dashboard contains different charts and filters to make the
data easy to understand. Slicers can be used to filter the data
and check the results.

## Purpose

The main purpose of this project was to practice Excel data
analysis and create an interactive sales dashboard.
